# LastLight

A minimalist survival game where light is your life, your vision, and your weapon. Survive the darkness.

## Play on GitHub Pages

1. Create a GitHub repository named `LastLight`.
2. Unzip the release package.
3. Drag **all files inside the `LastLight` folder** into the root of the repository and commit them to `main`.
4. When you are ready to publish, open **Settings → Pages** in GitHub.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will provide a Pages URL. Open it in Safari on iPhone to play.

## Install on iPhone

Open the GitHub Pages URL in Safari, tap **Share**, then **Add to Home Screen**. LastLight is configured as a Progressive Web App and can run in its own app-like window. After it has loaded successfully, its service worker caches the core game files for offline use.

## Controls

- **Drag** anywhere in the play area to move.
- **Tap an enemy** to fire.
- Shooting consumes light.
- Defeated enemies can drop light that restores your reserves.
- If your light reaches zero, the run ends.

## Core idea

**LIGHT = LIFE = VISION = WEAPON**

The same finite resource determines how long you survive, how much of the world you can see, and how often you can attack.
